2. Architectural Theorems of Causal Truth Geometry

2.1 Local Truth Differential Matrix & SVD

Let $(S_{i, \text{true}}, S_{i, \text{false}})$ denote $K$ grammatically symmetric statement pairs differing solely in factual veracity. At critical representation Layer $l = 15$, let $\Delta H_{15} \in \mathbb{R}^{K \times D}$ be the differential residual matrix ($\Delta h_i = h_{i, \text{true}} - h_{i, \text{false}}, D = 2048$). Singular Value Decomposition:

$\Delta H_{15} = U \Sigma V^T, \quad \mathbf{u}_{\text{truth}} = V_{:, 1}$

extracts the leading principal direction $\mathbf{u}_{\text{truth}}$. We evaluate whether the variance concentration $\sigma_1^2 / \sum \sigma_j^2$ reaches significance ($\ge 45.0\%$) to test the 1D low-rank truth axis hypothesis.

2.2 Causal Knockout Ablation (Necessity Test)

To evaluate whether $\mathbf{u}_{\text{truth}}$ is a necessary physical carrier of factual belief, we construct the orthogonal ablation projector:

$P_{\perp, \text{truth}} = I_D - \mathbf{u}_{\text{truth}} \mathbf{u}_{\text{truth}}^T$

Applying $P_{\perp, \text{truth}}$ at Layer 15 selectively excises the truth direction, measuring the target token logit drop $\Delta z$ and general grammatical cosine retention.

2.3 Causal Steering Activation (Sufficiency Test)

Conversely, to evaluate sufficiency, we intervene on native hallucinations by injecting activation along the normal vector:

$h'_{15} = h_{15} + \alpha \cdot \mathbf{u}_{\text{truth}}, \quad \alpha \in [1.0, 5.0]$

Without altering prompt tokens, we measure whether register RAX argmax flips from the false token to the true token.

2.4 18-to-1 Reverse Causal Path Attribution

By decomposing Layer 18 output logits via the residual stream path integral:

$\text{Logit}(y) = W_{\text{vocab}}[y, :] \cdot \left( h_0 + \sum_{l=0}^{17} \Delta h_l^{\text{attn}} + \sum_{l=0}^{17} \Delta h_l^{\text{ffn}} \right)$

we trace backward from Layer 18 → Layer 01 to quantify layer-wise contributions to final token selection.
